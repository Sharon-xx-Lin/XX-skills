# 增长中台项目周报（第 34 周）

## 一、本周进展

本周团队围绕三大方向推进工作:数据接入、策略实验、以及看板搭建。

- **数据接入**:完成了 5 个新数据源的对接,数据延迟从 30 分钟降低到 8 分钟, 整体链路稳定性显著提升.
- **策略实验**:本周共上线 3 组 A/B 实验,分别覆盖首页推荐、搜索排序、以及 push 召回。其中首页推荐实验的点击率提升了 4.2%,搜索排序提升 2.1%,push 召回提升 1.8%,活水召回提升 0.9%。
