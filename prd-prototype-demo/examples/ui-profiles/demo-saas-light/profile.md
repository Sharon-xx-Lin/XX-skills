# 示例产品 UI 档案（demo-saas-light）

> ⚠️ **这是合成示例，不是任何真实产品。** 配色是编的，用于让你跑通流程、验证安装。
> 正式使用请用 `scripts/sample_ui.py` 采样你自己的产品截图。

## 基本信息

浅色主题的 B 端桌面 SaaS，形态类似「侧边栏 + 顶栏 + 数据表格」的工作台。

## 布局骨架

```
顶栏      48px   面包屑 + 右侧操作按钮组
侧边栏   220px   分组导航，选中态用浅蓝底 + 蓝色文字
内容区          Tab + 工具栏 + 表格
```

## 信息密度

表格行高 32px、一屏 15~20 行。控件高度 32px。卡片间距 12px。
**这一节最关键** —— 行高 60px、一屏五行的话，即使配色全对也一眼假。

## 双主色分工

- **品牌紫 `--brand`**：Logo、装饰性强调，不用于按钮
- **功能蓝 `--primary`**：主按钮、链接、选中态文字

## 交互范式

- 选中态：浅蓝底 + 蓝色文字（不用下划线加粗）
- hover：`--bg-hover` 浅灰底
- 分层：靠 1px 发丝边框，几乎不用阴影
